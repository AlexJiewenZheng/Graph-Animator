Graph Animator

Visualizer tool

About

Made by Alex Zheng

This tool will animate any math equations for you to visualize. Just enter any math equation, an interval to animate, the animation time and then click animate! I attached a link to my github and source code down below!

Documentation

Operators and Syntax

Enter your equation in terms of just x (no other variables). Use parenthesis for order of operations.

Fractions

To animate y = x + 3 2 , enter in (x+3)/2

Exponents

To animate y = x2, enter in x^2

Multiplication

To animate y = 2x, enter in 2*x

Multiple equations

To animate multiple equations, separate them with commas. For example: (x+3)/2, x^2, 2*x

Supported Functions

Basic

abs(x), sqrt(x), cbrt(x), nthRoot(x,n) (nth root of x), x! (factorial)

Logarithms

log(x) (natural log), log10(x) (base 10 log), log2(x)(base 2 log)

Basic Trig

sin(x), cos(x), tan(x), sec(x), csc(x), cot(x)

Inverse Trig

asin(x), acos(x), atan(x), asec(x), acsc(x), acot(x)

Hyperbolic

sinh(x), cosh(x), tanh(x), sech(x), csch(x), coth(x)

Inverse Hyperbolic

asinh(x), acosh(x), atanh(x), asech(x), acsch(x), acoth(x)

Special functions

gamma(x)

Settings

Interval to animate [x1, x2]

This setting controls where the animation is drawn. The animation will start at x = x1 and animate all the way to x = x2.

X-axis & Y-axis Bounds

This setting controls the maximum and minimum values of x and y shown on the grid.

Grid Spacing

This setting determines the number of units between grid lines.

Animation Time

This is the total time it takes for the animation to start and finish.

Square Grid Checkbox

If this is checked, the grid lines will form perfect squares. This means it will change the Y-axis bounds based on the X-axis bounds.
